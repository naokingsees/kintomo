# きんトモ

開くのが楽しい。見た瞬間にやる気が出る筋トレ記録アプリです。
インストール不要で、スマホのブラウザから使えます。

## できること

- **ホーム**:今日の応援メッセージ、継続日数、今週の目標、今日のメニュー
- **トレーニング記録**:重さ・回数を大きなボタンで入力。前回の記録を自動で表示
- **休憩タイマー**:セットの間に自動でスタート
- **ふりかえり**:カレンダーと、週ごと・種目ごとのグラフ
- **バッジ**:継続日数・自己ベスト・合計回数などの達成を集める
- **目標**:週に何回やるか、休憩の長さ、画面の色(明るい/暗い)
- **種目リスト**:体の場所ごとに選べて、自分で種目を追加することもできます

## スマホのホーム画面に追加する

- **iPhone(Safari)**:共有ボタン →「ホーム画面に追加」
- **Android(Chrome)**:メニュー(︙)→「ホーム画面に追加」または「アプリをインストール」

一度開けば、電波のない場所でも使えます。

## 記録の保存について

記録はその端末のブラウザの中だけに保存され、どこにも送信されません。
そのため、ブラウザのデータを消したり、別の端末で開いたりすると、記録は引き継がれません。

## サンプル表示

アドレスの最後に `?demo` を付けると、サンプルの記録が入った状態で表示されます(保存はされません)。
